# Stack & Queue from Scratch

Implementimi i klasave `Stack` dhe `Queue` në Python pa koleksione të gatshme,
me metodat `push`, `pop`, `peek`, `is_empty` dhe `__iter__`, si dhe dy demonstrime:
kontrolli i kllapave (bracket matching) dhe planifikimi i detyrave (task scheduling).

**Lënda:** Data Structures & Algorithms
**Autoret:** Altina Abazi, Blenda Abazi
